# Benchmarking-PPO-SAC-and-TD3-for-Generalizable-Robotic-Arm-Manipulation-in-MuJoCo
An online reinforcement-learning benchmark. PPO, SAC and TD3 each learn a pick-and-place task on a simulated 4-DoF robotic arm in MuJoCo, from scratch, by interacting with the simulator and generating all of their own experience.
